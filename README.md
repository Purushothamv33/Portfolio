- Mobile navigation drawer

- Animated counters

- 3D hover tilt on project cards
- Floating AI/code panels

DEPLOY
------
Keep these files together. Add your resume.pdf to the same folder if you want the Resume button to work.
Open the HTML directly in Chrome for a local preview, or upload the files to your hosting.
